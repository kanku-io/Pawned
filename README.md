# PAWNED

A streetwear e-commerce storefront built with React and Vite, featuring a Supabase backend and PayFast payment integration. Designed and developed from scratch as a portfolio project.

## Features

- Homepage with hero section and category navigation
- Responsive, mobile-first design
- Product data managed via Supabase

## Tech Stack

- **Frontend:** React, Vite, CSS
- **Backend / Database:** Supabase (PostgreSQL, Storage)
- **Payments:** PayFast *(planned)*
- **Deployment:** Vercel
